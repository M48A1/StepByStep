# Snell



```bash
bash <(curl -Ls https://raw.githubusercontent.com/M48A1/StepByStep/refs/heads/main/snell.sh)
```

也可以下载后直接运行：

```bash
wget -O snell.sh https://raw.githubusercontent.com/M48A1/StepByStep/refs/heads/main/snell.sh && chmod +x snell.sh && ./snell.sh
```

安装后输入 `snell` 打开管理菜单，直接显示版本、运行状态、开机启动、监听地址、节点地址和网络模式。选择 `8` 查看 Surge 节点，也可运行 `snell info`。
